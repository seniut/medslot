# Prompt — Review Before Release

```text
Review this repository/branch before release.

Check:
- booking flow correctness;
- cancellation flow correctness;
- manual booking correctness;
- working hours logic;
- double-booking protection;
- patient data exposure on public pages;
- admin authorization;
- i18n completeness;
- Prisma migrations;
- GDPR/RODO-relevant behavior;
- logs and sensitive data;
- docs/changelog updates.

Return:
1. Release blockers.
2. Important non-blocking issues.
3. Suggested improvements.
4. Validation commands to run.
5. Manual test checklist.
```
