# Prompt — Add New Feature Safely

```text
I want to add this feature:

<PASTE FEATURE DESCRIPTION>

Please analyze first:
- Is it MVP or post-MVP?
- What data model changes are needed?
- What privacy/GDPR risks exist?
- What i18n changes are needed?
- What admin/public UI changes are needed?
- What tests/manual validation are needed?
- What docs must be updated?

Then propose a small implementation plan. Do not start coding until the plan is clear.
```
