# Prompt — Build MVP Step by Step

```text
Implement the next unfinished milestone from PLANS.md.

Before coding:
1. Identify the milestone.
2. List files that will change.
3. Identify database, i18n, privacy, and documentation impacts.
4. Propose a short implementation plan.

During coding:
- Keep scope narrow.
- Follow AGENTS.md and copilot instructions.
- Update docs and CHANGELOG.md.
- Add or update migrations if needed.

After coding:
- Run pnpm check if possible.
- If DB changed, run Prisma validation commands.
- Provide manual test steps.
```
